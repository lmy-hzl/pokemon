# 宝可梦对战游戏 (Pokemon Battle Online)

一款支持键盘操控和联机对战的宝可梦回合制游戏。

## 功能特点

- 🎮 **键盘操控**：完全支持键盘操作，无需鼠标
- 🌐 **联机对战**：通过房间号与朋友联机对战
- ⚔️ **回合制战斗**：经典宝可梦回合制战斗系统
- 🔥 **属性克制**：完整的属性克制系统
- 💊 **异常状态**：中毒、麻痹、睡眠、冰冻等状态效果
- 🎯 **10只宝可梦**：妙蛙种子、小火龙、杰尼龟、皮卡丘、耿鬼、拉普拉斯、快龙、超梦、喷火龙、卡比兽

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动服务器

```bash
npm start
```

服务器默认在 `http://localhost:3000` 启动。

### 开始游戏

1. 打开浏览器访问 `http://localhost:3000`
2. 一位玩家点击 **创建房间**，获得5位房间号
3. 将房间号分享给朋友，朋友点击 **加入房间** 输入房间号
4. 双方各选择一只宝可梦
5. 对战开始！

## 键盘快捷键

| 界面 | 按键 | 操作 |
|------|------|------|
| 大厅 | `1` | 创建房间 |
| 大厅 | `2` | 加入房间 |
| 大厅 | `Enter` | 确认加入 |
| 选择宝可梦 | `← →` 或 `A D` | 切换宝可梦 |
| 选择宝可梦 | `↑ ↓` 或 `W S` | 上下切换 |
| 选择宝可梦 | `Enter` 或 `空格` | 确认选择 |
| 对战 | `1` `2` `3` `4` | 使用对应技能 |
| 对战 | `← →` 或 `A D` | 切换技能 |
| 对战 | `Enter` 或 `空格` | 使用选中技能 |
| 对战结束 | `R` | 再来一局 |
| 对战结束 | `Q` | 返回大厅 |

## 技术栈

- **后端**：Node.js + Express + Socket.io
- **前端**：原生 HTML/CSS/JavaScript
- **通信**：WebSocket (Socket.io)
